## 二、核心设定

### 2.1 彗星事件

Miller 彗星在聚会当晚近距离经过地球。此后手机信号消失、屏幕碎裂、电力中断。[证据 A]

**电影实际展示的效果**：
- 手机屏幕同时碎裂 [FILM|HIGH|CONFIRMED]
- 手机信号消失 [FILM|HIGH|CONFIRMED]
- 电力中断 [FILM|HIGH|CONFIRMED]
- 一个碎掉的杯子（无人记得打破它） [FILM|HIGH|CONFIRMED]
- 房屋之间的黑暗区域变得"异常浓密" [FILM|HIGH|CONFIRMED]
- 不同现实开始重叠/可见 [FILM|HIGH|CONFIRMED]

### 2.2 多重现实

彗星经过期间，同一条街上的同一栋房子存在**多个平行版本**。每个版本的聚会有微小但关键的差异。[FILM|HIGH|CONFIRMED]

**核心机制**：
- 穿过室外黑暗区域 → 到达另一个现实的房子。目的地看起来随机 [INFERENCE|LOW|HYPOTHESIS]（电影未证明"完全随机"，见 OPEN_QUESTIONS U12）
- 目的地看起来随机 [INFERENCE|LOW|HYPOTHESIS]（电影未证明"完全随机"，见 U12）
- 返回原现实纯靠运气 [FILM|HIGH|CONFIRMED]
- 不止两个现实——至少存在多个 [FILM|HIGH|CONFIRMED]
- 人物可能**不知不觉**穿越现实 [FILM|HIGH|CONFIRMED]

### 2.3 黑暗区域

房屋之间的浓密黑暗区域是现实之间的"通道"。[FILM|HIGH|CONFIRMED]

**已确认性质**：
- 穿越者到达另一个现实 [FILM|HIGH|CONFIRMED]；目的地随机性为推断 [INFERENCE|LOW|HYPOTHESIS]
- 不保证回到出发点 [FILM|HIGH|CONFIRMED]
- 黑暗区域穿越：电影未展示身体伤害 [INFERENCE|LOW|UNVERIFIED]（"未展示伤害"≠"穿越必然安全"，见 OPEN_QUESTIONS U11）
- 两个群体在黑暗中相遇（蓝/红荧光棒） [FILM|HIGH|CONFIRMED]

**尚无法确认**：
- 黑暗区域的精确边界 [DESIGN|N/A|PENDING_USER]
- 是否可以选择目的地 [DESIGN|N/A|PENDING_USER]
- 穿越是否受意志控制 [DESIGN|N/A|PENDING_USER]

### 2.4 现实验证方法

人物使用多种物理标记来辨别自己属于哪个现实：[FILM|HIGH|CONFIRMED]

| 方法 | 说明 | 效果 |
|---|---|---|
| 荧光棒颜色 | 蓝/红/绿标记不同群体 | 可区分群体，不能区分个体 [FILM|HIGH|CONFIRMED] |
| 随机物品盒 | 每个群体选随机物品放入盒中 | 有效但可以重复 [FILM|HIGH|CONFIRMED] |
| 编号照片 | 骰子随机数写在照片背面 | 有效 [FILM|HIGH|CONFIRMED] |
| 记忆对照 | 各自的记忆是否一致 | 最可靠但最难验证 [FILM|HIGH|CONFIRMED] |
| 便签 | 留言传递信息 | 可能被不同现实的版本看到 [FILM|HIGH|CONFIRMED] |

### 2.5 科学解释（人物理论，非电影确认规则）

Hugh 的物理学家兄弟给了他一本关于量子退相干的书。[FILM|HIGH|CONFIRMED]

**人物提出的理论**：
- 量子退相干（decoherence）作为解释框架 [INFERENCE|MEDIUM|PARTIAL]（Hugh 的书]
- 薛定谔的猫思想实验（Hugh 解释） [FILM|HIGH|CONFIRMED]
- "一个现实会在彗星经过后坍缩"（人物推测） [INFERENCE|LOW|HYPOTHESIS]
- "每个决定导致现实分裂"（人物推测） [INFERENCE|LOW|HYPOTHESIS]

**注意**：以上理论来自电影人物，**不等于电影已确认的客观规则**。电影从未给出最终解释。

## 三、核心主题

1. **选择与可能性**：如果能重来，你会选择哪个版本的自己？[INTERVIEW|MEDIUM|CONFIRMED]（导演访谈]
2. **身份认同**：当存在多个你时，"你"是谁？[A: 电影展示]
3. **信任崩溃**：当同伴可能来自另一个现实时，如何信任？[FILM|HIGH|CONFIRMED]
4. **道德边界**：为了更好的生活，你愿意付出什么代价？[A: Emily 的选择]

## 四、对 COMET 游戏的核心锚点

必须保留的叙事锚点（A 级事实）：
1. 聚会之夜 + 彗星经过
2. 手机/电力异常作为第一信号
3. 黑暗区域 = 随机现实穿越
4. 8 人 + 复杂人际关系
5. 随机物品盒 + 编号照片作为现实验证
6. 信息差与信任崩溃
7. Emily 的最终选择（暴力替换另一个自己）
8. 结尾的电话（悬念保留）

可扩展的（D 级原创）：
- 玩家探索更多现实的可能性
- 玩家选择改变事件发展
- 多结局（不只电影一种）
- 更详细的房间内探索
- NPC 主动行为和对话
