## 现实分支图（简化）

```
初始现实 A（8 人聚会，蓝荧光棒）
├── 停电 → 手机碎裂
├── Hugh + Amir 外出 → 到达现实 B（亮灯房）
│   ├── 返回时已非原版（红荧光棒暴露）
│   └── "真" Hugh + Amir 后来返回
├── Em + Kevin + Mike + Laurie 外出
│   └── 遇到红荧光棒群体（现实 C 或 D）
├── Mike 单独外出勒索 → 到达现实 D
├── 便条重复出现 → 确认多现实
├── 验证盒创建 → Emily 的归属分析
├── Em 离开 → 探索多个房子
│   ├── 暴力现实
│   ├── 其他变体
│   └── "完美"现实（Em-Kevin 和谐）
│       └── Em 暴力替换另一个自己
└── 彗星碎裂 → 现实窗口关闭
    └── 结尾电话（悬念保留）
```
