# Coherence Research Supplement

本目录存放 ChatGPT 对《Coherence》(2013) 的公开资料研究补充，供 COMET 项目研究和 WorkBuddy 阅读。

## 文件
- [RESEARCH_PACKET.md](./RESEARCH_PACKET.md)：事件链、人物信息差、道具线索、制作方式和 COMET 设计启发。
- [SOURCE_REGISTER.md](./SOURCE_REGISTER.md)：公开访谈、对白文本和二手剧情分析的来源登记及使用限制。

## 阅读须知
本研究基于公开导演访谈、公开对白文本和二手剧情资料交叉整理，不是逐镜头原片考证。所有结论区分电影事实、角色观点、研究推断、游戏设计建议和未确认事项。不得将角色理论或影迷现实编号模型直接写成电影客观规则。

## 与 Film Bible 的关系
这是补充研究包，不替代 `docs/film/` 下既有 Film Bible 文档。若要吸收进正式 Film Bible，应由维护者逐项核验来源和证据等级，并保留未解决问题。
