# COHERENCE 研究补充包：事件链、人物信息差与道具线索

> 研究用途：为 COMET（基于《Coherence》(2013) 的第一人称叙事游戏）提供可追溯的电影研究补充材料。
>
> 研究边界：本文由公开导演访谈、公开对白文本和公开剧情资料交叉整理。研究者没有在本轮逐镜头观看原片，也没有完成逐帧、逐镜头、精确时间码或完整户型核验。因此，本文不能被称为逐镜头考证，也不能替代原片画面核验。
>
> 版本：2026-11-01
> 适用分支：recovery/visual-rebuild
> 与既有 Film Bible 的关系：补充研究材料，不覆盖既有文档；如与既有文档冲突，应先记录差异并核验来源，不要静默覆盖。

## 0. 证据与表述规则

本文使用以下标记：

- **[F-D] 导演访谈事实**：导演在公开访谈中明确陈述的制作过程或创作意图。
- **[F-T] 对白文本事实**：公开对白文本中明确出现的台词或事件描述。它不能证明画面构图、动作细节或镜头时间。
- **[F-P] 公开剧情资料**：公开剧情简介或影评中的情节概括，可能存在省略或解释偏差。
- **[I] 研究推断**：根据多项资料提出的解释，不应写成电影确立的客观规则。
- **[G] COMET设计建议**：面向游戏的原创设计建议，不是电影事实。
- **[U] 未确认**：需要原片画面、可靠制作资料或进一步来源核验。

重要区分：
1. 角色亲眼观察到的内容，不等于角色对观察的解释。
2. 角色提出的科学理论，不等于电影世界的客观规则。
3. 角色判断自己来自哪个现实，不等于研究者已经确认其归属。
4. 分析者为方便解释而建立的现实编号，不是电影官方编号。
5. 游戏设计建议不能反向写入 Film Bible 的电影事实章节。

## 1. 导演的创作与拍摄方法

### 1.1 没有传统完整剧本，但有严格的总体结构

[F-D] Byrkit 与联合编剧 Alex Manugian 花费约一年规划整体故事、线索、转折和人物弧线；演员没有拿到传统完整剧本，而是在拍摄期间分别收到与自己角色有关的背景、动机或当晚任务。演员不知道其他演员收到什么，也不知道完整故事将如何发展。

来源：
- Den of Geek 访谈：https://www.denofgeek.com/movies/director-james-ward-byrkit-talks-coherence/
- 366 Weird Movies 访谈：https://366weirdmovies.com/interview-james-ward-byrkit-coherence/
- Movie Mom 访谈：https://moviemom.com/interview-james-ward-byrkit-coherence/
- The Dissolve 访谈：https://thedissolve.com/features/emerging/633-how-james-ward-byrkit-constructed-coherence/

[F-D] 电影在导演自己的住宅拍摄，历时五个晚上。演员可以在房屋内自由行动，摄影机跟随他们；导演描述过演员自行进行晚餐聚会、长镜头和即兴对话的拍摄方式。

### 1.2 对 COMET 的启发

[G] 可以借鉴“导演掌握全局结构、角色只掌握局部动机与信息”的创作方法：
- 叙事设计层掌握客观事件顺序与必要的戏剧节点。
- 每个 NPC 只掌握自己的角色背景、亲历事件和收到的转述。
- NPC 不应读取全局剧情答案。
- 玩家通过观察、交谈、比较和行动逐步形成自己的判断。
- NPC 的即兴感来自有限信息下的自然反应，而不是随机生成无因果台词。

[G] 住宅应首先像真实生活空间，再逐渐成为悬疑发生地。不要把电影的低预算拍摄限制误解为“场景可以随意简化”；真实生活感来自空间关系、家具用途、物品状态和人物活动。

## 2. 电影事件链（阶段级，不是逐镜头时间线）

以下顺序是公开对白文本和剧情资料支持的阶段性整理。不同现实中的精确归属、人物穿越路径和部分细节存在解释争议。

### 阶段 1：普通晚餐聚会与潜在关系矛盾
[F-T] 八名朋友在 Mike 和 Lee 家聚会。Emily 与 Kevin 的旅行计划、Laurie 与 Kevin 的过去、Mike 与 Beth 的秘密关系等关系张力在异常发生前已经存在。
[I] 彗星事件不是凭空制造人物矛盾，而是放大原本就存在的关系问题。

### 阶段 2：停电与远处仍亮灯的房屋
[F-T] 聚会期间停电，人物注意到附近远处有一栋仍然亮灯的房屋。手机通信也出现问题。Hugh 与 Amir 外出调查。
[U] 房屋与街道的精确空间距离、视线关系和摄影机位置，需原片画面核验。

### 阶段 3：外出经历与第一批异常物品
[F-T] Hugh 与 Amir 返回，带回包含人物照片和其他物品的盒子；照片背面有数字。Hugh 描述自己在另一栋房屋看到与聚会有关的场景。
[F-T] 人物开始比较照片、手写记录和自己的记忆。
[I] 这是从“外部异常”转向“身份和现实可信度危机”的关键节点。

### 阶段 4：主动调查与重复人物
[F-T] 一组人物外出调查，遇到与自己相似的另一组人，并使用不同颜色的荧光棒作为辨认线索。
[U] 各组人物在每次外出后所处现实的精确对应关系，不能只依赖影迷编号图。

### 阶段 5：标记、记录与现实判断
[F-T] 人物使用照片、数字、荧光棒、骰子、盒子、笔和杯垫等物品尝试识别所在房屋。
[I] 标记系统降低了不确定性，却不能保证正确；标记本身也可能被其他现实的人复制、移动或误认。

### 阶段 6：现实错位与关系秘密曝光
[F-T] 人物发现彼此的经历、物品状态和记忆对不上。原本存在的关系秘密也进一步暴露。
[I] 现实危机与人际危机形成反馈：越不信任彼此，越难共同确认事实；越难确认事实，越容易怀疑彼此。

### 阶段 7：Emily 的目标发生变化
[F-T] Emily 从参与群体调查逐渐转向主动寻找她认为更好的现实。
[I] 她的动机应理解为逐步变化：最初的关系不安和人生选择遗憾，经过异常事件与比较，逐渐转化为主动寻找另一种生活的愿望。不要把她开场就写成已有明确替代计划。

### 阶段 8：结尾的身份疑问
[F-T] 结尾留下 Emily 与另一个现实、另一个自我之间的身份问题。
[I] 结尾的力量来自“她是否真的得到想要的生活”与“她是否能够确认自己是谁”之间的冲突，而不是简单宣布某个现实编号正确。

## 3. 人物信息差：谁知道什么

### 3.1 人物信息表

| 人物 | 可确认的主要信息来源 | 认知盲区与设计注意 |
|---|---|---|
| Emily | 自己与 Kevin 的关系、旅行选择、亲自观察到的异常、逐步收集的线索 | 不具备全知视角；现实归属判断可能错误 |
| Kevin | 与 Emily 的关系、与 Laurie 的过去、亲历的聚会和异常 | 不一定理解 Emily 的真实想法；对 Laurie 的边界处理存在张力 |
| Mike | 聚会主人身份、与 Beth 的秘密、自己经历的异常 | 压力下可能更想控制局面；不能默认知道其他现实发生的事 |
| Lee | 与 Mike 的婚姻、与 Beth 的友谊、亲历的聚会事件 | 不一定知道 Mike 与 Beth 的秘密；不能自动知道外出者经历 |
| Beth | 与 Mike 的秘密、与 Lee 和 Hugh 的关系、自己亲历的事件 | 知道秘密不等于所有人知道；不同现实中的经历不能自动同步 |
| Hugh | 兄弟提供的彗星相关信息、外出经历、物理学解释 | 理论解释不是客观真相；可能误判现实归属 |
| Amir | 与 Hugh 外出、接触盒子和线索、自己的判断 | 不应成为 Hugh 的附属角色；同行不代表两人认知完全一致 |
| Laurie | 与 Kevin 的旧关系、与 Amir 的关系、群体变化 | 对 Emily 的评价可能受私人关系影响，不能当作客观结论 |

### 3.2 认知信息的四种来源

[G] 建议所有角色认知至少区分：

1. **亲历**：自己亲眼看见、亲耳听见或亲自操作。
2. **转述**：由另一个角色告诉自己；角色知道“对方这样说过”，不代表转述内容已被证实。
3. **推断**：根据观察和记录形成的解释。
4. **误解/错误记忆**：角色相信某事，但其认知可能与客观事件不一致。

示例：
- 客观事件：Hugh 带回一个盒子。
- Emily 亲历：Emily 看见盒子和照片。
- Emily 转述所得：Hugh 声称自己在另一栋房屋看到聚会。
- Emily 推断：她怀疑存在多个相似现实。
- 未确认：Emily 尚不能证明 Hugh 的现实归属。

### 3.3 对 COMET 现有系统的设计约束

[G] 事件发生不代表所有 NPC 同时知道。
[G] NPC 可能相信错误的事情，但系统应将“角色相信”与“世界事实”分开。
[G] 玩家认知独立于 NPC 认知；玩家不能因数据库中存在事件就自动获得信息。
[G] NPC 对话应同时参考人物经历、认知、关系和当前情绪，而不是只看全局剧情阶段。
[G] 关系应是多维的，不宜仅用单一好感度值表示；信任、熟悉、嫉妒、愧疚、戒备等关系状态可能分别变化。

## 4. 关键道具与视觉线索

### 4.1 照片与数字
[F-T] 盒子中出现八个人的照片，照片背面有数字。人物比较照片内容、拍摄背景和手写数字。
[G] 照片应具有可比较的内容与背景；玩家需实际查看才获得观察记录。
[G] 记事本保存玩家自己记录的信息，不应自动显示世界数据库中的全部答案。
[U] 每张照片的精确画面、角度和出现顺序需原片核验。

### 4.2 荧光棒
[F-T] 电影中使用不同颜色的荧光棒。它们最初是黑暗环境中的照明/辨认物，后来成为人物区分不同房屋和人群的标记。
[I] 颜色不是可靠的现实编号；物品可能被拿走或转移。
[G] 游戏记录应关注物品当前持有者、来源、状态与转移历史，而不只是颜色。

### 4.3 盒子与随机标记
[F-T] 人物使用盒子、骰子、杯垫、笔和照片尝试建立更独特的房屋标记。
[I] 这是人物试图降低误认概率的办法，不是保证正确的数学证明。
[G] 不应将其简化成固定颜色+数字的单一密码；标记可能被复制、交换、误读。

### 4.4 手机
[F-T] 手机通信受影响；人物注意到手机外观状态差异，并把手机当作现实辨认线索。
[F-D] 导演在访谈中将手机、戒指、照片、花瓶等描述为人物试图抓住的身份凭据。
[G] COMET 手机可承载联系人、聊天、玩家拍摄的照片、备忘录、通知和未接来电，但不应成为万能任务菜单。
[G] 手机内容也可能不完整或与玩家当前经历不一致。

### 4.5 戒指
[F-T] 戒指与 Emily、Kevin 的关系有关，结尾再次强化身份与关系疑问。
[I] 它主要是私人关系与身份认同线索，不应仅作为普通可拾取物。
[G] 记录其赠送关系、人物记忆、持有者和不同现实中的状态；人物对它的理解可能不同。

### 4.6 花瓶、书籍、杯子、餐桌等生活物件
[F-D] 导演在访谈中提到保留了电影中的书籍和花瓶等物品，并称它们是叙事中的“小型棋子”。
[F-T] 餐桌、杯子、蜡烛、书籍和家居物件参与聚会和异常场景。
[G] 生活物件不必全部成为可调查谜题；它们首先应有合理用途和摆放位置。少量物品状态变化可以成为玩家比较现实的参照。
[U] 物品在各镜头中的精确位置、朝向和状态变化需画面核验。

## 5. COMET 的道具数据建议（概念草案）

重要道具可考虑保存以下维度：
- item_id：稳定标识
- category：线索、关系、环境等主要类别
- owner/current_holder：拥有者或当前持有者
- current_location：当前地点
- state：外观、完整度、是否使用等状态
- history：世界中发生的转移、修改和使用事件
- known_by：哪些人物知道哪些变化
- observed_by_player：玩家是否实际观察
- evidence_source：观察、转述或推断

示意 JSON（仅为设计草案，不代表当前代码字段）：

```json
{
  "item_id": "living_room_vase",
  "category": "environment",
  "current_location": "living_room_shelf",
  "current_holder": null,
  "state": {
    "condition": "intact",
    "placement": "shelf"
  },
  "history": [],
  "known_by": [],
  "observed_by_player": false
}
```

注意：世界事件历史与人物认知历史必须分开。若 actor 未知，应记录“当前未确认执行者”，不能把它解释为“事件没有执行者”。

## 6. 对住宅、空间与场景重建的启发

[F-D] 电影在导演自己的住宅拍摄，演员可在房屋内自由活动，摄影机跟随演员行动。导演描述了让演员把住宅当作自己的家、自然取用物品和进行聚会的拍摄方法。

[G] 对 COMET 的建模启发：
- 先建立可信的日常住宅，再让异常逐渐破坏玩家对空间的熟悉感。
- 家具应符合日常用途、尺寸和通行关系。
- 餐桌、椅子、沙发、厨房台面、照片、书籍和杂物应有生活化摆放逻辑。
- 现实变体优先通过物品状态、家具位置、灯光和人物活动差异体现，不要只依赖墙面换色。
- 先精修一个客厅/餐厅垂直切片，再扩展其他空间。
- 黑暗区域应被当作户外空间过渡与不确定性机制，而不是简单的纯黑房间。
- 概念平面图不得标为电影真实户型；未经画面证实的空间关系必须标注为推测或游戏补充。

## 7. 重要的不确定性与禁止过度断言

以下内容不得在没有新证据时写成电影客观规则：
- 穿过黑暗区域必然安全。
- 目的地完全随机且概率均等。
- 现实数量必然无限。
- 某角色的现实归属已经被研究者完全确认。
- 角色提出的量子退相干解释就是电影宇宙的真实机制。
- 任何颜色、数字或物品标记都能百分之百识别现实。
- 电影住宅具有已经确认的完整户型图和精确房间尺寸。

公开对白文本不能证明：
- 演员的精确肢体动作和表情；
- 镜头构图、摄影机运动和剪辑点；
- 道具在每个镜头中的精确位置；
- 事件发生的精确时间码；
- 未在对白中提及的房间连接关系。

## 8. 对 COMET 的阶段性设计结论

1. 叙事核心应是信息不对称、人物关系与现实不确定性的交织，而不只是多栋房屋。
2. 客观事件、NPC经历、NPC认知和玩家认知必须分层。
3. 人物可以误解事实，但游戏不能把误解写成客观真相。
4. 道具的来源、持有者、状态、历史和知情者，比单纯物品名称更重要。
5. 生活物件首先要建立住宅真实感，之后才可能成为线索。
6. Emily 的动机应有渐变过程，不应从开场就被写成全知且目标明确。
7. 电影现实编号图、人物归属表和空间平面图均需标注证据等级。
8. 本研究包是 Film Bible 的补充研究，不是用户对 COMET 原创剧情、选择、结局和玩法的最终授权。

## 9. 下一轮待研究事项

- 逐场景梳理住宅内部、门窗、走廊、厨房、室外与远处房屋的空间关系。
- 若能取得合法可访问的原片画面，建立镜头索引：时间码、空间、人物位置、道具位置、视线方向、动作和连续性。
- 为八名人物补充可观察的行为习惯、说话方式、压力反应、关系矛盾和不同经历下的差异。
- 将所有现实归属图拆分为“角色当时判断”与“研究者基于证据的推断”。
- 对照 COMET 当前实现，逐项标注“电影依据 / 用户设计 / 技术实现 / 待确认”，不替用户决定原创剧情。
