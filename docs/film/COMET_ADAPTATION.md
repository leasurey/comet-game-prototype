## 一、原电影事实 vs 游戏核心设定

### 必须保留的原作核心（A 级事实）
1. 聚会之夜 + 彗星经过 [A]
2. 手机/电力异常作为第一信号 [A]
3. 黑暗区域 = 随机现实穿越 [A]
4. 8 人 + 复杂人际关系（含秘密） [A]
5. 随机物品盒 + 编号照片作为验证机制 [A]
6. 信息差与信任崩溃 [A]
7. Emily 的核心动机：职业遗憾 + 情感不安全感 [A]

## 二、如何让玩家以 Emily 的身份亲历事件

### 核心体验
玩家扮演 Em，经历信任崩溃的全过程。

**设计原则**：
1. **第一人称探索**：观察环境、检查物品、触发对话
2. **认知限制**：玩家只知道 Em 在那个时刻知道的
3. **选择权**：可以决定是否外出、和谁对话、如何验证
4. **不可逆性**：一旦穿越，可能无法回来

### 信息获取方式
| 方式 | 电影中的对应 | 游戏实现 |
|---|---|---|
| 观察环境 | Em 注意到碎杯子 | examine 热点 |
| 对话 | 听到其他人的讨论 | NPC 对话 |
| 物理检查 | 盒子/照片/便条 | 物品检查 |
| 自主推理 | Em 的归属分析 | 玩家的逻辑推理 |

## 三、如何让玩家主动探索

### 空间探索
- 聚会主空间 → 厨房 → 走廊 → 办公室 → 前门/侧门 → 后院 → 黑暗区域
- 每个空间都有线索和互动点
- 不同现实的同一空间有差异

### 时间探索
- 对话有时间敏感性（错过可能不再有）
- 某些事件只能在特定时刻触发
- 不同时间的同一空间有不同状态

---

## 四、如何让 NPC 根据各自经历反应

### NPC 认知模型
每个 NPC 有自己的：
- **memory**：经历的记忆
- **known_facts**：学到的事实
- **relationships**：关系状态
- **identity_reality**：来自哪个现实

### 对话响应
- NPC 只知道自己经历的
- 同一问题在不同现实下可能不同
- 关系影响对话选项
- 秘密在特定条件下暴露

## 五、如何让玩家选择影响结局

### 可影响的事件【待用户确认】
| 事件 | 电影版本 | 游戏选择 |
|---|---|---|
| 是否外出调查 | Hugh/Amir 外出 | 玩家可以决定是否去 |
| 如何验证现实 | 创建验证盒 | 玩家选择验证方式 |
| 如何处理"另一个自己" | 暴力替换 | 可以选择和平/暴力/其他 |
| 是否揭露秘密 | 勒索信暴露 | 何时/是否揭露 |
| 最终选择 | 去"完美"现实 | 可以留在原地/探索/替换 |

### 多结局方向【待用户确认】
1. **电影结局**：替换成功但被电话揭穿（悬念）
2. **和平结局**：与另一个自己共存
3. **放弃结局**：接受现状，不追求"更好"
4. **悲剧结局**：替换失败或代价太大

## 七、如何避免玩家提前知道角色不应该知道的

### 认知分离系统
- **客观世界**：实际发生的事情
- **玩家认知**：Em 观察/听到/推断的
- **NPC 认知**：每个 NPC 自己的经历

### 实现建议【待用户确认】
- 对话 gate 需要玩家知道特定事实
- 某些信息只能通过特定途径获取
- NPC 不会说出自己不知道的
- 环境线索需要主动观察

---

## 八、如何让现实差异具有叙事意义【待用户确认】

### 不是"换家具"
每个现实的差异应该反映：
1. **关系变化**：谁和谁在不同现实有不同关系
2. **事件变化**：某件事在不同现实有不同结果
3. **情绪变化**：不同现实的氛围不同
4. **信息变化**：不同现实的人知道不同的事

### 示例【待用户确认】
- "完美"现实：Em-Kevin 和谐，没有 Laurie 的威胁
- 暴力现实：群体互殴
- 信息差异：某些现实的人知道彗星异常，某些不知道

## 设计权限边界【第二轮新增】

| 类别 | 决定权 | 说明 |
|---|---|---|
| 电影原作事实 | 电影 | 不可改变 |
| 研究推断 | 研究者提出 | 可被推翻/修正 |
| 游戏原创设计 | **待用户确认** | 研究者只提建议 |
| 最终剧情走向 | **用户决定** | 研究者不得擅自决定 |
| 玩家选择/多结局 | **用户决定** | 需用户审定方案 |

**研究者的职责**：提供分析、提出建议、标注不确定性。
**研究者不能做**：替用户决定剧情、把建议写成已定设计、补造证据。
