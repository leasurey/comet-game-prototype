# 阶段性交付物索引

本目录归档 COMET 项目从「场景考古」到「系统整合修复」各轮任务的正式交付文档。
按时间顺序排列，每一份都是当轮任务书的对应产物。

> 说明：日常维护的文档（架构、验收、已知问题、版本记录等）仍在 `docs/` 根目录。
> 本目录只放**已封版**的阶段交付物，移动后不再改动内容，仅在需要时追加勘误。

## 阅读建议

- 想了解**为什么房子是这个尺寸**：读 2 → 3 → 4，三轮是逐次推翻与收紧的过程，第 3 轮纠正了第 1 轮的倒推错误。
- 想了解**当前实现是什么**：读 5 和 8，其余是设计依据。
- 想了解**还有哪些坑没填**：读 6 的问题优先级表，以及 8 结尾的未完成项。

## 注意

这些文档里的尺寸与坐标**均为设计值**，其中标注 `[未验证]` 的条目在当时的 Godot 版本中未经实跑确认。
实际实现以 `tools/house/` 下的构建源码为准——文档与源码冲突时，源码为准。
