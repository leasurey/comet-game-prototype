### 测试框架自身修正两处

- 超时判断原先用**渲染帧**计数，headless 不限帧率，几百帧可能只过 0.1 秒，把正常步骤误杀。改为**物理帧**。
- P06 起点原选 (-4.0, 6.0)，正好压在咖啡桌边角，玩家被 `move_and_slide` 沿桌边推向东侧。改到 (-2.5, 8.5) 空地。

## 五、性能实测

环境：Godot 4.7.2，Compatibility / OpenGL 3.3，Windows 10，1280×720。

| 指标 | 实测值 | 来源 |
| --- | --- | --- |
| 场景加载耗时 | **42 ms** | `Time.get_ticks_usec()` 包住 `enter_location` |
| 平均 FPS | **57** | 真实窗口连续采样 |
| 最低 FPS | **41** | 同上 |
| 静态内存 | **57.5 MB** | `Performance.MEMORY_STATIC` |
| 视频显存 | **16.3 MB** | `Performance.RENDER_VIDEO_MEM_USED` |
| 帧内图元 | **344** | `RENDER_TOTAL_PRIMITIVES_IN_FRAME` |
| 帧内绘制调用 | **13** | `RENDER_TOTAL_DRAW_CALLS_IN_FRAME` |
| 场景网格数 | 89 | 场景文件统计 |
| 静态碰撞体 | 86 | 场景文件统计 |

> **关于 CPU / GPU 使用率**：Godot 不提供系统级 CPU/GPU 占用率 API，本项目也未接第三方监控。
> 上表只包含引擎自报的渲染计数器，**不含 CPU/GPU 百分比**。这一项属于未采集，不是"已优化"。
>
> **关于 GPU**：目标机型标称 AMD Radeon 530，但本次未能确认运行时实际使用的是独显还是 Intel HD 620 核显。
> 该信息只影响性能结论的适用范围，需在后续正式测试中确认。
