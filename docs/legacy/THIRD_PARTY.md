# 第三方素材与许可证说明

本项目坚持一个原则：**优先使用自制素材，任何外部来源都必须可追溯。**

## 结论

| 类别 | 来源 | 许可证 | 是否可自由分发 |
| --- | --- | --- | --- |
| 全部游戏代码 | 本项目原创 | MIT | 是 |
| 全部 3D 场景几何体 | 本项目脚本程序生成 | MIT | 是 |
| 图标 `assets/icon.svg` | 本项目手写 SVG | MIT | 是 |
| 游戏引擎 | Godot Engine 4.7.2-stable | MIT | 是 |
| 美术贴图 / 模型 / 音频 | **无** | — | — |
| 电影剧照 / 台词 / 音乐 | **无** | — | — |

## 逐项说明

### 1. 代码

仓库内所有 `.gd` / `.tscn` / `.json` 均为本项目原创，未复制其他开源项目的源代码。

`.tscn` 文件由 `tools/scene_builder.gd` 经 Godot 自身 `PackedScene.pack()` 生成，
等价于 Godot 编辑器产出的场景文件，不受 Godot 之外的授权约束。

### 2. 美术资源

**本项目不包含任何第三方美术资源。** 所有可见物体都由 Godot 内置的基础几何体
（`BoxMesh`、`CylinderMesh`）配合 `StandardMaterial3D` 纯色材质构成，
几何体与材质参数全部写在 `tools/scene_content.gd` 里，可完整审阅与修改。

这样做有两个考虑：
1. 避免把来源不明或禁止再分发的素材带进仓库；
2. 原型阶段聚焦在机制而非美术，低多边形 + 纯色块足以验证「世界差异」这一核心。

### 3. 图标

`assets/icon.svg` 为手写 SVG 矢量图形，无外部图库成分。

### 4. Godot Engine

本项目使用 Godot Engine 4.7.2-stable（官方发布，commit `ed1daf0bf`），
引擎本身采用 MIT 许可证。

需要注意：**以 Godot 制作的游戏不受引擎许可证约束**，
作者有权为自己的游戏选择任意许可证；本仓库选择 MIT 是基于自身意愿，而非引擎要求。

### 5. 灵感来源声明

本项目以电影《Coherence》（2013，中文译名《彗星来的那一夜》）为**叙事灵感**。

本项目：
- 不包含该电影的任何画面、音频、台词、角色形象或商标；
- 不复述电影剧情，也不在原著之外补充所谓「设定细节」；
- 仅借鉴「熟悉的地点在不知不觉间变得不同」这一叙事构想。

名称 COMET 为项目自拟代号，与电影官方英文名 Coherence 无关联。

## 若后续引入第三方资源，必须补充的字段

| 字段 | 说明 |
| --- | --- |
| 资源名称 | 资源的原始名称 |
| 原始作者 | 作者或工作室名称 |
| 来源地址 | 可访问的完整 URL |
| 许可证 | 许可证全称，例如 CC-BY-4.0 |
| 本地路径 | 在仓库中的存放位置 |
| 修改说明 | 是否经过修改 |

不得仅仅因为「某个网页能看到」就假定资源可以自由再分发。
