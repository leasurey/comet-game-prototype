# COMET 剧情事件目录 v1

状态：设计草案。ID 为稳定候选；触发条件是概念描述，尚未适配当前 EventManager schema。
改编类型：A=保留电影核心；B=扩展；C=玩家分支；D=原创。

每个事件都记录：触发条件、参与人物、世界变化、玩家信息、后续影响、存档要求和容错策略。

## 第一幕：聚会与关系建立

### EVT-001 到达聚会住宅
- 电影锚点：T00–T01；类型 A。
- 触发：新游戏开场，Emily 到达聚会地点。
- 参与：Emily、Kevin（电话/抵达阶段）。
- 世界变化：进入聚会前状态；通讯异常作为线索，不立即解释。
- 玩家信息：与 Kevin 有未谈完的话题；手机异常原因未知。
- 后续：进入聚会；可先探索或交谈。
- 存档：章节阶段、初始认知、开场事件唯一性。
- 容错：读档不重复播放开场。

### EVT-002 聚会人员到齐
- 锚点：T01；类型 A。
- 触发：玩家进入主空间且聚会准备完成。
- 参与：八人。
- 世界变化：NPC 进入聚会行为状态，背景活动开始。
- 玩家信息：通过现场介绍认识人物，不自动获得全部关系史。
- 后续：自由探索和选择交谈对象。
- 存档：NPC instance_id、位置/行为、介绍事件。
- 容错：缺席介绍可由后续对话补获。

### EVT-003 Kevin 的未来安排
- 锚点：T01；类型 A/B。
- 触发：与 Kevin 讨论相关话题。
- 参与：Emily、Kevin。
- 世界变化：记录双方表达，不自动锁定关系结局。
- 玩家信息：Kevin 希望 Emily 考虑同行；Emily 的回应由玩家决定。
- 后续：坦诚、回避或暂缓，影响后续关系对话。
- 存档：选择 ID、关系状态、对话进度。
- 容错：可稍后继续讨论。

### EVT-004 Laurie 到场引发关系张力
- 锚点：T01–T02；类型 A/B。
- 触发：Laurie 到场，Emily 处于可观察范围。
- 参与：Emily、Kevin、Amir、Laurie。
- 世界变化：NPC 站位/对话组合变化。
- 玩家信息：可观察 Kevin 反应；过去关系需逐步了解。
- 后续：开启相关话题。
- 存档：到场事件、玩家是否在场、观察记录。
- 容错：玩家不在场不能授予亲眼观察事实，可由转述补获。

## 第二幕：异常开始

### EVT-005 通讯异常
- 锚点：T03；类型 A。
- 触发：玩家尝试通讯或讨论信号问题。
- 参与：Emily、可选 NPC。
- 世界变化：通讯状态设为不可用。
- 玩家信息：确认通讯失败，不知道原因。
- 后续：角色提出不同解释。
- 存档：通讯状态、玩家尝试记录。
- 容错：重复尝试不重复触发主事件。

### EVT-006 停电
- 锚点：T04；类型 A。
- 触发：剧情时间窗口到达且聚会状态满足。
- 参与：全体在场角色。
- 世界变化：灯光、电源和环境音切换。
- 玩家信息：观察到停电，不自动知道彗星是原因。
- 后续：查看外部环境、讨论异常。
- 存档：停电状态、灯光状态、事件唯一性。
- 容错：玩家不在主空间时也可通过环境声/光变化获知，来源记为环境观察。

### EVT-007 发现远处亮灯住宅
- 锚点：T04；类型 A。
- 触发：玩家到达可观察位置并看到亮灯房屋，或 NPC 明确指出。
- 参与：Emily、在场 NPC。
- 世界变化：远处住宅成为已发现地点。
- 玩家信息：看到房屋仍亮灯；“它是另一现实中的同一栋房子”仍属推断。
- 后续：讨论是否外出。
- 存档：地点发现、信息来源、是否亲眼看到。
- 容错：转述只能授予 hearsay，不授予 inspect。

### EVT-008 Hugh 与 Amir 首次外出
- 锚点：T05；类型 A。
- 触发：两人决定外出。
- 参与：Hugh、Amir、Emily（观察者）。
- 世界变化：NPC 离开主空间，记录实例 ID、时间和目标。
- 玩家信息：在场时知道两人离开，不知道其后经历。
- 后续：等待、查看门口或与留守者交谈。
- 存档：NPC 实例、离开事件、时间和目标。
- 容错：场景卸载不能销毁个人经历。

### EVT-009 Hugh/Amir 带回盒子
- 锚点：T06；类型 A。
- 触发：符合本次归来条件的 Hugh/Amir 实例进入住宅。
- 参与：Hugh、Amir、Emily、在场 NPC。
- 世界变化：盒子与物件进入场景；Hugh 伤情可见。
- 玩家信息：看到盒子和伤情；无法立即确认他们是否是刚才离开的同一实例。
- 后续：检查盒子、照片、询问人物。
- 存档：盒子内容、NPC instance_id、伤情、来源现实。
- 容错：玩家缺席时物件仍存在，但不授予亲眼检查事实。

### EVT-010 检查盒子与照片
- 锚点：T06；类型 A/B。
- 触发：玩家主动检查盒子/照片。
- 参与：Emily；Amir 可作为对话对象。
- 世界变化：记录检查状态，不篡改物件内容。
- 玩家信息：获得照片人物和标记细节。
- 后续：对照当前人物、提出问题。
- 存档：物品状态、事实 ID、来源和现实 ID。
- 容错：重复检查不重复授予事实，可回看内容。

### EVT-011 门外出现重复便条
- 锚点：T07；类型 A。
- 触发：Hugh 写完便条、门口状态更新，玩家检查门口。
- 参与：Hugh、Emily；留言者来源未知。
- 世界变化：门口出现便条副本。
- 玩家信息：看到内容相同的便条，来源身份未知。
- 后续：讨论复制、时间错位或其他解释。
- 存档：便条实体 ID、文本版本、发现状态、未知来源标记。
- 容错：场景重载不删除便条；重复检查不生成副本。

## 第三幕：多现实假说

### EVT-012 第二组人员前往亮灯住宅
- 锚点：T08；类型 A。
- 触发：玩家选择同行，或剧情进入组队外出阶段。
- 参与：Emily、Kevin、Laurie、Mike。
- 世界变化：记录队伍和离开前实例。
- 玩家信息：同行则亲历；不同行则只能通过返回者描述了解。
- 后续：目击另一组人物和不同颜色标记。
- 存档：同行选择、队伍成员、时间、门级落点。
- 容错：不同行不软锁主线。

### EVT-013 看见另一组对应人物
- 锚点：T08；类型 A。
- 触发：队伍抵达观察点并完成视线确认。
- 参与：外出队伍、远处对应人物。
- 世界变化：记录跨现实目击。
- 玩家信息：看到相似人物和不同颜色标记；身份仍是推断。
- 后续：撤离/返回、讨论。
- 存档：目击事件、角色原型、观察来源。
- 容错：不自动登记远处人物为已确认 NPC 实例。

### EVT-014 量子退相干理论被提出
- 锚点：T09；类型 A/B。
- 触发：玩家检查相关书籍或参与 Hugh 的解释对话。
- 参与：Hugh、Emily、在场 NPC。
- 世界变化：理论资料可阅读。
- 玩家信息：获得“可能存在多个现实”的解释模型，标记为角色理论。
- 后续：赞同、怀疑或追问。
- 存档：阅读进度、听闻来源、玩家立场。
- 容错：书籍可稍后阅读，亦可由对话补获但来源不同。

### EVT-015 建立房屋身份标记
- 锚点：T10；类型 A/B。
- 触发：玩家参与或旁观照片/数字/物件标记过程。
- 参与：在场角色。
- 世界变化：当前房屋标记数据建立。
- 玩家信息：理解标记用途，但标记不保证绝对唯一。
- 后续：对照其他房屋。
- 存档：标记内容、来源、创建现实 ID。
- 容错：缺席可通过检查或询问补获。

### EVT-016 人员身份与时间出现矛盾
- 锚点：T11；类型 A/B。
- 触发：玩家观察到时间描述、物件、伤情、标记或记忆互相矛盾。
- 参与：至少两名相关 NPC。
- 世界变化：记录矛盾，不自动宣布谁是“假的”。
- 玩家信息：获得矛盾观察，可推断人物副本发生替换。
- 后续：身份核验对话。
- 存档：矛盾证据、NPC 实例、玩家推断。
- 容错：每条证据独立保存，允许后续汇总。

### EVT-017 个人物品身份核验
- 锚点：T12–T13；类型 A/B。
- 触发：玩家对照个人物品与人物记忆/描述。
- 参与：Emily、Kevin、Laurie（按分支）。
- 世界变化：记录对照结果。
- 玩家信息：某些记忆或物件细节不一致；结论取决于玩家实际观察。
- 后续：影响信任并开放追问。
- 存档：对照项目、来源、推断、关系变化。
- 容错：可重复核对，旧推断保留并可更正。

### EVT-018 现实数量不止两个的证据
- 锚点：T14；类型 A/B。
- 触发：收集到多条互不一致的标记、便条或人物经历。
- 参与：Emily、Hugh、Amir、Mike 等。
- 世界变化：更新多现实证据集合。
- 玩家信息：推断现实数量超过两个，不显示全局精确数量。
- 后续：群体制定更谨慎的识别办法。
- 存档：证据集合、推断版本、置信度。
- 容错：证据不足不强制触发。

## 第四幕：关系崩解

### EVT-019 关系越界被目击
- 锚点：T12；类型 A/B。
- 触发：玩家在场观察相关互动，或从目击者处听闻。
- 参与：Kevin、Laurie、Beth、Emily。
- 世界变化：关系状态和目击记录更新。
- 玩家信息：亲眼所见与转述分开；不自动推定动机。
- 后续：质问、隐瞒或与他人讨论。
- 存档：目击者、来源、关系变化、玩家选择。
- 容错：未目击时可获得转述版本。

### EVT-020 Mike/Beth 旧秘密曝光
- 锚点：T15；类型 A。
- 触发：玩家阅读便条，或角色明确转述。
- 参与：Mike、Beth、Hugh、Emily。
- 世界变化：群体关系改变；Hugh 获得此前未知信息。
- 玩家信息：Emily 根据实际来源得知秘密，不自动掌握全部细节。
- 后续：信任冲突和人物对峙。
- 存档：便条实体、阅读者、知情者集合、关系状态。
- 容错：便条错过时可由转述补获较弱事实。

### EVT-021 不同现实中的 Mike 出现
- 锚点：T16；类型 A/B。
- 触发：相关现实与人物实例进入同一场景。
- 参与：不同 Mike 实例、在场群体。
- 世界变化：出现身份冲突和危险场景状态。
- 玩家信息：通过行为与经历矛盾识别人物副本，不要求立即知晓全部来历。
- 后续：躲避、劝阻、调查或帮助角色脱离冲突。
- 存档：实例身份、冲突阶段、角色状态。
- 容错：恢复时不能复制或丢失角色；不设计现实伤害操作教程。

### EVT-022 群体信任崩解
- 锚点：T15–T16；类型 B/C。
- 触发：秘密曝光、身份矛盾和关系冲突达到组合条件。
- 参与：当前在场 NPC。
- 世界变化：分组、对话意愿、行为状态改变。
- 玩家信息：Emily 观察到群体不再共享同一解释。
- 后续：组织讨论、单独交谈或离开。
- 存档：群体状态、NPC 关系、已知事实。
- 容错：不能只由单一隐藏数值决定。

## 第五幕：选择与结局

### EVT-023 Emily 离开当前住宅
- 锚点：T17；类型 A/C。
- 触发：玩家选择独自探索，或满足离开条件。
- 参与：Emily；其他 NPC 可继续活动。
- 世界变化：进入街道与现实探索阶段。
- 玩家信息：知道当前局势无法令自己安心，目标转向寻找可接受的结果。
- 后续：探索其他住宅。
- 存档：离开原因、关系状态、章节阶段、出发位置。
- 容错：离开前允许返回，认知日志可回顾。

### EVT-024 观察其他现实
- 锚点：T18；类型 A/B。
- 触发：玩家到达其他住宅观察点。
- 参与：Emily、其他现实人物副本。
- 世界变化：发现新的现实变体。
- 玩家信息：只能观察局部，不自动知道房屋内部全部情况。
- 后续：比较不同生活状态。
- 存档：访问现实、观察片段、推断。
- 容错：可重复访问，保留来源记录。

### EVT-025 面对另一个 Emily
- 锚点：T19；类型 A/C。
- 触发：玩家选择介入某个现实并触发身份冲突。
- 参与：玩家 Emily、目标现实 Emily。
- 世界变化：身份、位置和结局状态产生后果。
- 玩家信息：知道自己正在影响另一个有主体性的个体。
- 后续：进入身份、责任和归属的结局选择。
- 存档：双方 instance_id、状态、事件结果、不可逆选择确认。
- 容错：不可逆结局前提供清楚叙事确认；读档后身份不能错乱。

### EVT-026 彗星窗口结束
- 锚点：T20；类型 A/B。
- 触发：剧情时间/章节状态满足；具体机制由游戏设定。
- 参与：当前现实中的角色。
- 世界变化：跨现实过渡条件最终变化。
- 玩家信息：Emily 可观察环境变化，但不能知道所有现实最终状态。
- 后续：结局结算。
- 存档：彗星阶段、现实锁定状态、结局条件快照。
- 容错：只结算一次；读档不重新开启已关闭窗口，除非加载更早档。

### EVT-027 次日身份余波
- 锚点：T21；类型 A/C。
- 触发：结局路径进入次日阶段。
- 参与：Emily、Kevin、相关 NPC。
- 世界变化：按路径呈现表面正常、身份矛盾或其他结局。
- 玩家信息：通过戒指、来电和人物反应理解选择代价。
- 后续：结束、后日谈或隐藏结局。
- 存档：结局 ID、关键选择、人物身份映射、结局证据。
- 容错：结局存档可重复读取，不重复执行副作用。

## 游戏原创扩展事件（非电影事实）

### EVT-G01 玩家建立线索板
- 类型 D；触发：玩家获得至少三条相关观察/听闻/阅读记录。
- 参与：Emily。
- 世界变化：建立个人线索组织界面。
- 玩家信息：可自行连接线索，系统不宣布推断必然正确。
- 后续：形成显式推断记录。
- 存档：线索连接、备注、推断版本。

### EVT-G02 玩家向 NPC 分享线索
- 类型 D；触发：正式对话中选择分享已知信息。
- 参与：Emily、目标 NPC。
- 世界变化：NPC 知识更新，来源记录为 Emily 转述。
- 玩家信息：知道自己分享了什么；NPC 是否相信另行记录。
- 后续：可能改变信任、话题和行为。
- 存档：接收者、事实 ID、转述时间、信任变化、接受状态。

### EVT-G03 NPC 自主交换信息
- 类型 D；触发：NPC 在合适场景、关系和时间条件下交流。
- 参与：相关 NPC。
- 世界变化：NPC 之间传播信息，形成来源链。
- 玩家信息：Emily 只有在附近听见、后来被告知或观察结果时才知道。
- 后续：信息差改变，影响后续回应。
- 存档：交流事件、参与者、传播内容和来源。
- 容错：NPC 私下交流不能让 Emily 自动获得知识。

## 全局存档概念要求

| 类别 | 至少保存 |
|---|---|
| 剧情 | 当前章节、事件触发记录、分支选择 |
| 世界 | world_id、现实变化历史、物件状态 |
| 玩家认知 | fact_id、source_kind、source_id、world_id、tick、certainty、retracted |
| NPC | character_id、instance_id、world_id、position、behavior、experience、knowledge、belief、relationships |
| 对话 | 已完成节点、选择记录、话题解锁来源 |
| 物品 | item_id、状态、内容版本、被谁观察 |
| 结局 | 条件快照、结局 ID、不可逆状态 |

## 最小垂直切片

先实现：EVT-006 停电 → EVT-007 发现亮灯住宅 → EVT-008 Hugh/Amir 外出 → EVT-009 盒子归来 → EVT-010 检查盒子 → EVT-011 重复便条。

验收：
1. 玩家是否在场会影响认知来源。
2. NPC 离开/返回后实例身份可追踪。
3. 盒子和便条是客观物件状态，不是一次性弹窗。
4. 认知事实能解锁真实对话，不靠测试注入。
5. 场景卸载、重进、保存、读档后事件不倒退。
6. 同一事件不重复生成物件或重复改变世界。
