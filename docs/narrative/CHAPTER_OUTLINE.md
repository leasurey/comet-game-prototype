## 一、章节大纲（序章 + 6 章）

| 章 | 现实层 | 一段话大纲 | 章末 cliffhanger |
|---|---|---|---|
| **序章 · 车内+玄关** | alpha | 开篇为 P−1 车内对话（【电影】STORY_DESIGN E01，补写小节见本节末），随后沿用 `data/opening.json` P0–P3 既有节拍：进门→与 Kevin 交谈→八副餐具的餐桌→全屋停电+远处玻璃脆响。P0–P3 文本直接复用，不加分支；序章总时长 ≤15 分钟（P−1 压缩为 1 个节拍）。 | 灯灭了。远处那栋房子，还亮着。 |
| **1 · 对面亮着的房子** | alpha | Mike 最先发现街对面亮着灯。玩家可选择性勘察主屋（便签"4"、灶台钟 7:05 等自家基准项入册）。镜像屋 L1/L2 差异在本章转写为**可收集观察条目**（烧短的蜡烛、七人合影的空位、空钥匙盘、拉开的椅子、多出的一副餐具）。玩家首次面临"要不要过街"的选择——过街能拿一手事实，但 Hugh 会说你不在的时候屋里发生了事。 | Hugh 和 Amir 带着一只盒子回来了。盒子里是我们自己的东西。 |
| **2 · 七分钟** | alpha→beta | 盒子验物（E06 电影事实：乒乓球拍、照片、数字）。玩家比对灶台钟 7:12 vs 7:05，得出"对面不是跟着我们走的"这一推断。选择是否跟随 Hugh 走黑暗路段（E05 的"是否外出"变体）——走了，拿 `fact_dark_road` 且进 beta；不走，从回来者的转述里拼图（转述有错漏，后文要付代价）。 | 黑暗尽头，一支**红色**荧光棒朝你们晃了晃。 |
| **3 · 验证盒** | beta | 骰子、随机物品、数字（E09）。全员各自验证归属，秘密开始暴露（Mike-Beth）。玩家选择站边/调解/回避（E10）：站 Mike 侧得真相失人心，站 Lee 侧得人心失真相，回避则两边都记你一笔。本章新增**身份凭据抉择**：是否把戒指交给 Kevin 保管（分支 3-3/3-4）。宝丽来降级为纯观察线索：对屋壁炉 8 张 + FarPolaroids 二级观察，只承载"对面也在做标记"的信息，不再被"我们这栋"拾获。 | 盒子里的数字不是我们的笔迹。这栋房子也在做标记——而且比我们仔细。 |
| **4 · 冷光** | beta→gamma | 再次穿越，gamma：电灯冷色+蜡烛同亮、对面西翼三盏灯全亮而自家没有。Beth 的灵性直觉在此层**意外地准**（她"感觉"到的人是真是假取决于第 3 章信任值）。玩家可在对面书房发现书架钉眼（L3-2：这栋房子没人查过书）与摊开的纸——两条互斥的推论入口。 | 那张便签上的数字，是 7。可我们门上那张，写的是 4。 |
| **5 · 便签上的 7** | gamma→alpha | A3 便条重复成为主谜题：数字在递增，说明"有人在按顺序来"。玩家用 markers_seen 自组证据链判定"这一桌八个人里谁不是原来那位"。本章最大取舍：**指认某人是替身**（可能指错，信任全面受损）vs **先指认自己**（Hugh 会认真对待你，但全桌开始怀疑你）。章中含一次**剧情强制穿越**例外（gamma→alpha，固定链不变，由叙事触发而非玩家行走，见 §五）——cliffhanger 之前，世界自己动了。 | 你终于确定了自己在哪个现实——同时确定有一件事，你回来之后就不可能再证明。 |
| **6 · 聚会之前** | 按玩家路径 | 证据链闭合后的最终选择：留在当前现实 / 穿越黑暗去找"原版" / 交换位置。结局矩阵判定（见 §3）。若 `surrendered_marker=true`，玩家自己已经在第 3–5 章把"你是你"的证据交了出去——终章没有任何选项能救回来。 | —— |

> 每章场景 = 单一住宅拓扑（主屋/街道/对面屋），文字版不需要 3D 场景切换；现实层差异即章节之间的**同一房间不同状态描写**——这是镜像屋设计直接转写的最大红利。

### 序章开篇小节 · P−1 车内对话（【电影】出处：STORY_DESIGN E01）

> N6 补写，插在 `data/opening.json` P0 之前，沿用其节拍格式与文本风格。E01 规格（STORY_DESIGN.md L10–22）：参与人物 Em、Kevin；玩家行为 = 2–3 个对话选项；可能结果 = 影响 Em 初始情绪 flag；【电影事实】存在此场景。压缩为 1 个节拍、约 600–800 字、3–4 分钟，保证序章总时长 ≤15 分钟。

```json
{
 "id": "p_m1_car",
 "objective": "去聚会的路上",
 "on_enter": [
  {"kind": "message", "text": "夜路。雨刷停了。Kevin 单手扶着方向盘，把暖气又调高了一格。"},
  {"kind": "message", "text": "「Mike 说人到齐了才开饭。」他顿了顿，「Laurie 也来。Amir 带她来的。」"},
  {"kind": "message", "text": "车拐进这条街。这一带的房子在夜里长得都差不多，只有一扇门廊的灯亮着。"},
  {"kind": "choice", "options": [
   {"text": "「我为什么要介意。」", "set_flag": "mood_guarded"},
   {"text": "「……有一点。但你下周就要走了，Kevin。」", "set_flag": "mood_anxious"},
   {"text": "不接话，看窗外掠过的灯。", "set_flag": "mood_quiet"}
  ]}
 ],
 "complete": {"kind": "choice_made"},
 "next": "p0_arrival"
}
```

> 三个选项只设定初始情绪 flag（`mood_guarded / mood_anxious / mood_quiet`），供第 1 章个别台词取变体，不进结局判定——E01 的电影功能是"设定关系基调"，不是隐藏分（支柱 3：选择无对错）。`complete.kind = "choice_made"` 为对话系统既有选择节点的复用写法，若工程侧 opening 驱动器不支持，降级为 `dwell` 即可，不影响文案。
