## 阅读建议

1. 先读 `REBUILD_BLUEPRINT.md`——了解全貌、现有系统分类、阶段计划
2. 根据你关心的领域读对应文档
3. 所有"待用户确认"标记的问题需要你做创作决定
4. 电影事实 [FILM] / 研究推断 [INFERENCE] / 原创建议 [DESIGN] 严格区分

## 核心原则

**COMET 是《Coherence》的互动改编。** 所有设计从原作出发。
现有工程是技术积累，不是最终视觉设计的限制。
用户尚未确认蓝图之前，不开始实际重建。
