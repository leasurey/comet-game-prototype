## 一、设计依据与边界

**电影可确认的空间**【电影事实】：
- 聚会主空间（餐厅/客厅）：8 人长桌、沙发、壁炉
- 厨房：与主空间相通
- 走廊：连接主空间与卧室/浴室
- 浴室：Em 最终冲突地点
- 前门 / 侧门 / 后院门：三个出入口
- 露台/后院：Em 的车、最终冲突
- 车道、街道、远处亮灯的房子

**电影未确认**【待确认】：
- 精确户型、房间尺寸、门窗位置、家具坐标
- 书房是否存在（Hugh 查书处可能只是某个房间）
- 地下室（用户提及，电影未明确出现）

**结论**：完整户型必须标为【游戏原创设计】。


## 十一、第二轮修订：按电影考据补建西翼（2026-11-01）

### 修订依据

`docs/film/FILM_LOCATIONS.md` 明确列出：

| 空间 | 证据等级 | 电影中的作用 |
|---|---|---|
| 走廊 | FILM \| HIGH \| CONFIRMED | 连接主空间与卧室/浴室；Beth 在此目睹 Laurie 亲吻 Kevin |
| 卧室 | FILM \| HIGH \| CONFIRMED（存在）| 走廊尽头 |
| 浴室 | FILM \| HIGH \| CONFIRMED | Emily 在此制服另一个自己 |

**改造前的问题**：住宅里既没有走廊，也没有卧室；卫生间被安排在玄关旁，
与「走廊连接主空间和卧室/浴室」这一电影明确结构不符。

### 新增布局（GAME_LAYOUT）

电影只确认了房间的**存在与连接关系**，没有展示户型尺寸。
以下划分全部是原创设计，不宣称是电影原貌：

```
        ┌──────────────┬──────────────┐
   z9.2 │   主卧        │              │
        │  (床/衣柜/    │              │
        │   床头柜)     │   走廊        │
   z5.0 ├──────────────┤  (1.35 宽)    │
        │   浴室        │              │
        │ (马桶/洗手台/ │              │
        │   浴缸)       │              │
   z2.5 ├──────────────┤              │
        │   洗衣房      │              │
        │  (洗衣机/柜)  │              │
   z0.2 └──────────────┴──────┬───────┘
                              │ 门洞 z 7.95~9.05
                        ┌─────┴─────┐
                        │  主空间    │
                        └───────────┘
```

| 空间 | 范围（x / z） | 面积 | 标注 |
|---|---|---|---|
| 走廊 | -8.05 ~ -6.70 / 0.20 ~ 9.20 | 1.35 × 9.0 | GAME_LAYOUT |
| 主卧 | -11.14 ~ -8.11 / 4.98 ~ 9.20 | 3.03 × 4.22 | GAME_LAYOUT |
| 浴室 | -11.14 ~ -8.11 / 2.52 ~ 4.98 | 3.03 × 2.46 | GAME_LAYOUT |

房屋总尺寸从 13.4 × 9.4 扩到 **17.9 × 9.4 = 168.3 m²**。

### 家具

新增 `props.bed / wardrobe / washer`，并在西翼布置：
主卧（双人床 + 床头柜 + 衣柜 + 边柜）、
浴室（马桶 + 洗手台 + 浴缸）、洗衣房（洗衣机 + 储柜）。

### 顺带修掉的两个真实缺陷

1. **马桶堵住卫生间门洞**：马桶原在 z=3.20，而卫生间门洞在 z 2.40~3.60，
   马桶正好把门堵死 → 「卫生间→书房」寻路间歇性失败。移到 z=0.52。
2. **书桌横在书房中部**：1.40 m 宽的桌子把走道挤到 navmesh 腐蚀余量以内。
   改为贴西墙纵向摆放（旋转 90°）。

P0–P3 的全部触发区域（玄关 / 客厅 / 餐桌 / 前门）坐标未变，
`opening_flow_test` 14 条断言仍全部通过；停电逻辑新增识别
`HallLamp / BedLamp / BathLamp` 三盏西翼灯。
