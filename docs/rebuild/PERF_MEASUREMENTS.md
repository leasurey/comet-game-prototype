# 性能实测记录（目标硬件）

> 本机即任务书指定的目标低配机型，因此以下数据是**目标机实测**，不是估算。

## 一、测试环境

| 项目 | 实测值 |
|---|---|
| CPU | Intel Core i5-7200U @ 2.50GHz |
| 内存 | 11.7 GB |
| GPU | AMD Radeon (TM) 530（厂商 ATI Technologies Inc.） |
| 操作系统 | Windows 10 教育版 |
| 引擎 | Godot 4.7.2，GL Compatibility |
| 分辨率 | 1280 × 720 |
| 场景 | `party_house`（聚会住宅），7 名 NPC 全部在场 |

采集方式：`tools/measure_perf.gd` 在真实运行的游戏里采样，
每机位先预热 3 秒，再连续采样 6 秒，记录平均/最低 FPS 与当帧 draw call。

```bash
godot --path . --resolution 1280x720 --script res://tools/measure_perf.gd
```

## 二、实测结果（2026-11-01）

| 机位 | 平均 FPS | 最低 FPS | draw calls | objects |
|---|---|---|---|---|
| 玄关（看向屋内） | 59.3 | 55.0 | 306 | 323 |
| 客厅（沙发/壁炉方向） | 60.0 | 60.0 | 238 | 258 |
| 厨房（L 形台面方向） | 60.0 | 60.0 | 144 | 164 |

场景节点总数：828。

## 三、结论

- 三个典型机位均为 **60 FPS（垂直同步上限）**，最低 55 FPS 出现在玄关开场
  （此机位能同时看到客厅、餐厅、厨房三个区域，视锥内物体最多）。
- 当前几何规模：静态网格 504 个、静态碰撞体 55 个、NPC 7 个（各约 16k 三角面）。
- 未出现卡顿或帧率骤降，没有触发低配降级方案的必要。

## 四、已知风险

1. **draw call 偏高**。玄关视角 306 个，主要来自家具的细分构件
   （一扇柜门、一个拉手都是一个 MeshInstance3D）。
   当前帧率仍满 60，但若后续继续加细节，建议做**同材质合批**
   （每件家具合并成一个多 surface 的 ArrayMesh），可把 draw call 压到 1/3 以下。
2. **本记录只覆盖聚会住宅**。室外街区、黑暗区域尚未重建，其几何规模与光照开销
   未纳入本次测量。
3. **未测试长时间运行**（内存增长、GC 抖动）。当前只验证了 20 秒稳态。

## 五、复现方式

```bash
godot --path . --resolution 1280x720 --script res://tools/measure_perf.gd
```

脚本会打印 GPU 名称与三个机位的采样结果，可直接对照本表复核。
