# 美术规范与性能限制

> **目标**：电影写实风格。可信的空间 > 高精度模型。
> **低配**：i5-7200U / 12GB / Radeon 530 2GB / Win10

---

## 一、模型规范

| 类型 | 面数上限 | 说明 |
|---|---|---|
| NPC 人体 | 5K-15K 三角 | 低多边形+好材质 |
| 主要家具 | 2K-5K 三角/件 | 桌椅、沙发 |
| 装饰道具 | 200-1K 三角/件 | 杯子、书、花瓶 |
| 建筑外壳 | 10K-30K 三角 | 墙体、屋顶 |
| 全场景总面数 | < 300K | 目标 |

## 二、材质规范

| 项目 | 限制 | 说明 |
|---|---|---|
| 材质总数 | < 50 个 | 共享材质 |
| 纹理尺寸 | ≤ 1024×1024 | 非关键 512×512 |
| PBR 材质 | 4 通道（ARMA） | 非 PBR 免 |
| 反射 | 仅金属件 | 节省 GPU |

## 三、灯光预算

| 项目 | 限制 | 说明 |
|---|---|---|
| 实时光源 | ≤ 8 个 | OmniLight |
| 阴影 | 仅主光源 | 其余关闭 |
| 环境光 | WorldEnvironment | 全局 |
| 光源 range | ≤ 8m | 减少计算 |
| 低配模式 | 全部关闭阴影 | 设置选项 |

## 四、NPC 预算

| 项目 | 限制 |
|---|---|
| 同屏 NPC | ≤ 7 人 |
| NPC 动画 | 30 FPS（低配 15 FPS） |
| NPC AI tick | 10 Hz |
| 导航更新 | 按需（非每帧） |

## 五、性能测试标准

| 指标 | 目标（低配） | 测量方式 |
|---|---|---|
| FPS | ≥ 30 | 室内行走 |
| 内存 | < 2GB | 任务管理器 |
| 加载时间 | < 5s/场景 | 计时 |
| 切换延迟 | < 2s | 现实切换 |

## 六、资源管理

- **场景按需加载**：只加载当前地点+相邻
- **现实变体共享材质**：差异通过 tint/emission 表达
- **LOD**：远景建筑用低模
- **纹理压缩**：VRAM 压缩
