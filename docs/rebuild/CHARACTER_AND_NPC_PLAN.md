# 人物与 NPC 重建方案

> 7 名 NPC 必须有可见人形模型。当前已有低多边形拼接体，需升级。

---

## 一、人物模型要求

| 项目 | 要求 | 当前状态 |
|---|---|---|
| 身体 | 人形比例（头身比 1:7），自然站姿 | 有（盒拼） |
| 头部 | 可辨识面部（简化即可） | 有（球体） |
| 服装 | 聚会休闲装（不同颜色） | 有（纯色） |
| 差异 | 7 人身材/发色/服装各不同 | 有 |
| 骨骼 | 支持基础动画 | 无 |
| 动画 | 站立/行走/转身/坐下/对话 | 无 |

**风格**：电影写实但不过度——低多边形+好材质+好动画 [DESIGN|PENDING_USER]

## 二、基础动画清单

| 动画 | 优先级 | 说明 |
|---|---|---|
| 站立（idle） | P0 | 呼吸微动、偶尔换重心 |
| 行走（walk） | P0 | 自然步态 |
| 转身（turn） | P0 | 面向对话对象 |
| 坐下/起身 | P1 | 餐桌、沙发 |
| 对话手势 | P1 | 说话时手部动作 |
| 情绪姿态 | P2 | 紧张/放松/愤怒 |

## 三、NPC 日常行为

| 行为 | 说明 | 现有系统支持 |
|---|---|---|
| 自主游荡 | 空闲时走动 | ✅ wander_callback |
| 社交对话 | NPC 之间交谈 | ✅ relationship |
| 使用家具 | 坐椅子、靠桌子 | ❌ 需加坐姿 |

| 事件响应 | 警觉/逃跑/聚集 | 部分 |
| 现实差异 | 不同现实行为不同 | ✅ world 切换 |
