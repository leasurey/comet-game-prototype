# 人物与 NPC 重建方案

> **制作路线**：先验证一个原型，再扩展七个。
> **风格**：电影写实（已确定，不再作为待选问题）。

---

## 一、制作路线：原型优先

### 第一步：Emily 人形原型（1 个）
1. 建立人形模型（身体/头部/面部/发型/服装）
2. 绑定骨骼（人形骨架）
3. 制作基础动画（站立/行走/转身/交谈/坐下/起身）
4. 材质（皮肤/布料/头发）
5. **在实际场景中测试**（比例/材质/动画/性能）
6. **用户提供截图确认视觉达标**

### 第二步：规范扩展（7 人）
1. 用同一骨架/制作流程
2. 调整外观差异（身高/体型/发色/服装）
3. 8 人同屏视觉检查

### 第三步：动画完善
1. 社交动画（两人交谈站位）
2. 情绪姿态（紧张/放松）
3. 家具使用（坐下/靠桌/拿杯子）

**验收标准**：提供实际游戏画面截图供用户检查，用户满意即可。不以"看起来像真人"为唯一标准。

---

## 二、Emily（玩家角色）

### 外观 [INFERENCE]
- 棕色长发、中等身材、舞者体态
- 聚会休闲装（毛衣+长裤）
- 无面部表情系统（第一人称不需）

### 行为 [INFERENCE]
- 日常：观察环境、检查物品、与人交谈
- 压力下：变得警觉、开始主动分析
- 说话方式：直接、有时犹豫、会问尖锐问题

### 与其他人的关系 [INFERENCE]
- Kevin：亲密但有疑虑
- Laurie：竞争/不安
- Mike/Lee：老友
- Beth/Hugh/Amir：朋友

### 不同现实经历 [INFERENCE]
- α：职业遗憾+Laurie 威胁
- β：关系和谐（可能无遗憾）
- 电影未展示其他完整经历 [INFERENCE]

## 三、七名 NPC 深度设计

### Kevin
- **外观**：深色短发、中等身高、休闲衬衫
- **说话方式**：温和、偶尔含糊、避免冲突
- **日常行为**：坐在沙发/站在餐桌旁、与 Em 亲近
- **压力反应**：试图调和、变得茫然
- **关系**：Em 男友、Laurie 前任
- **现实差异**：可能在不同现实与 Laurie 更亲近 [INFERENCE]

### Mike
- **外观**：金发/棕发、稍胖、T 恤
- **说话方式**：大声、偶尔说脏话、开玩笑
- **日常行为**：在客厅走动、喝酒、做手势
- **压力反应**：攻击性增强、提议暴力
- **关系**：Lee 丈夫、Beth 秘密情人
- **现实差异**：不同现实的暴力程度不同 [INFERENCE]

### Lee
- **外观**：深色长发、温柔面容、家居装
- **说话方式**：平静、调和、安排事物
- **日常行为**：在厨房/餐桌旁忙碌、照顾客人
- **压力反应**：试图维持秩序、最终崩溃
- **关系**：Mike 妻子、Beth 闺蜜
- **现实差异**：紧张程度不同 [INFERENCE]

### Beth
- **外观**：金发、灵性饰品（项链/手环）
- **说话方式**：含糊、灵性词汇、偶尔准确
- **日常行为**：坐在角落、拿着草药瓶
- **压力反应**：变得神秘、给出奇怪建议
- **关系**：Hugh 妻子、Mike 情人
- **现实差异**：草药效果/她的直觉准确性不同 [INFERENCE]

### Hugh
- **外观**：黑发、眼镜、衬衫
- **说话方式**：理性、引述科学、解释概念
- **日常行为**：站在书架旁、翻书、打电话
- **压力反应**：分析过度、试图理解规则
- **关系**：Beth 丈夫、Amir 伙伴
- **现实差异**：理解深度不同 [INFERENCE]

### Amir
- **外观**：深色头发、休闲装、年轻
- **说话方式**：快、兴奋、容易慌张
- **日常行为**：走来走去、帮忙、第一个去调查
- **压力反应**：恐慌、跟随他人
- **关系**：Hugh 伙伴、Laurie 邀请人
- **现实差异**：勇气/判断力不同 [INFERENCE]

### Laurie
- **外观**：金色长发、时尚装
- **说话方式**：暧昧、直接、自信
- **日常行为**：靠近 Kevin、与 Em 竞争
- **压力反应**：利用机会、变得更主动
- **关系**：Kevin 前任、Amir 邀请
- **现实差异**：在某些现实 Kevin 选择她 [INFERENCE]

## 四、动画清单

| 动画 | 优先级 | 用途 | 实现 |
|---|---|---|---|
| idle（站立） | P0 | 空闲 | 骨骼微动 |
| walk（行走） | P0 | 移动 | 骨骼动画 |
| turn（转身） | P0 | 面向对象 | 旋转+过渡 |
| talk（交谈） | P0 | 对话 | 手势+口型 |
| sit（坐下） | P1 | 使用家具 | 座位对齐 |
| stand_up（起身） | P1 | 离开座位 | — |
| lean（靠桌） | P2 | 放松 | — |
| gesture（手势） | P2 | 强调语气 | — |

## 五、NPC 状态机

```
[idle] → [walking] → [talking] → [idle]
  ↑         ↓           ↓
  └── [sitting] ←───────┘
```

每个状态有进入/退出动画过渡。NPC 在 idle 时自主游荡（已有 wander_callback）。
