# COMET 开场序章设计

> 目标：玩家第一次进入 COMET 时真正**经历**的内容，不是介绍文字。
> 第一人称、可自由移动、生活感 → 悬疑感渐强。

---

## 一、设计约束

**禁止**：
- 大段旁白解释设定
- NPC 排队自我介绍
- 只能点选项推进

**要求**：
- 玩家能走动、观察、交谈、接触物品
- 信息通过环境/行为/物品/对话**逐渐**呈现
- 不跳过人物关系建立

---

## 二、序章流程图

```
[P0] 玄关醒来/抵达
  ├─ 可行动范围：玄关 + 客厅入口
  ├─ 环境事件：室内灯光、隐约人声
  ├─ 可交互：门（已开）、鞋柜、便签
  └─ 结束条件：走进客厅
        ↓
[P1] 客厅初见
  ├─ 人物：Kevin（沙发旁）、其他 NPC 可留空
  ├─ 环境：沙发、壁炉、茶几
  ├─ 主动对话：Kevin 看到 Em 后主动招呼
  ├─ 可选对话：Em → Kevin（5 节点树）
  ├─ 可交互：茶几书本、壁炉、沙发
  └─ 结束条件：与 Kevin 对话完成 或 走到餐厅
        ↓
[P2] 餐厅与厨房
  ├─ 人物：（阶段 B 加入更多 NPC）
  ├─ 环境：8 人餐桌、厨房
  ├─ 可交互：餐桌杯子、厨房台面
  ├─ 时间推进：可设计"停电"触发
  └─ 结束条件：触发停电事件
        ↓
[P3] 停电与异常
  ├─ 环境：灯灭、蜡烛、手机碎裂
  ├─ 可交互：手机（看到裂屏）
  ├─ 剧情触发：Hugh/Amir 提议外出
  └─ 结束条件：序章结束，进入主循环
```

## 三、各阶段详细设计

### P0 玄关

| 项目 | 内容 |
|---|---|
| 玩家位置 | (0, 0.2, 1.6)，面向 -Z（客厅） |
| 可行动范围 | 玄关 2.4×1.8m + 客厅入口 |
| 场景人物 | 无（先听人声） |
| 环境事件 | 室内暖光、远处交谈声 |
| 主动对话 | 无 |
| 可选对话 | 无 |
| 可交互物品 | 前门（已开，可关）、鞋柜、**便签**（关键） |
| 剧情触发 | 走进客厅触发 P1 |
| 阶段结束 | 移动到客厅 |

**便签**：检查后获得 `fact_sticky_note`，解锁 Kevin 的深层对话。

### P1 客厅初见

| 项目 | 内容 |
|---|---|
| 玩家位置 | 客厅入口 (-1.0, 0.2, 4.0) |
| 可行动范围 | 客厅全域 |
| 场景人物 | Kevin（沙发旁） |
| 环境事件 | Kevin 抬头看到 Em，主动说"你站那儿有一会儿了" |
| 主动对话 | Kevin 发起（NPC 主动，非玩家按 E） |
| 可选对话 | Em → Kevin（kevin_vs_open 树） |
| 可交互物品 | 茶几书本、壁炉、沙发、地毯 |
| 剧情触发 | 对话完成 → 解锁 P2 |
| 阶段结束 | 对话结束 或 自行走向餐厅 |

### P2 餐厅与厨房

| 项目 | 内容 |
|---|---|
| 玩家位置 | 餐厅入口 (1.3, 0.2, 4.5) |
| 可行动范围 | 餐厅 + 厨房 |
| 场景人物 | 阶段 A 暂无（Kevin 可跟随） |
| 可交互物品 | 餐桌 8 椅、杯子、盘子、厨房台面、冰箱 |
| 剧情触发 | 停留 N 秒 或 检查餐桌 → 触发停电 |
| 阶段结束 | 停电 |

### P3 停电与异常

| 项目 | 内容 |
|---|---|
| 环境事件 | 灯灭 → 蜡烛亮 → 手机碎裂音 |
| 可交互 | 手机（裂屏）、蜡烛 |
| 剧情触发 | Hugh/Amir 提议去亮灯房 |
| 阶段结束 | 序章完成，移交主循环 |

## 四、情绪曲线

```
P0 玄关    → 平静、略带陌生
P1 客厅    → 温暖、关系张力（Kevin/Laurie）
P2 餐厅    → 日常、生活感
P3 停电    → 不安、第一丝诡异
```

**关键**：P3 的诡异必须建立在 P0-P2 的"正常"之上，不能一上来就悬疑。
