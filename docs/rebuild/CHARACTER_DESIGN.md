# COMET 人物设计

> 标注：【电影事实】/【人物解读】/【合理推断】/【游戏原创设计】/【待确认】
> **核心原则**：每个 NPC 有独立认知。Emily（玩家）知道 ≠ Kevin 知道。

---

## 一、认知模型（关键设计）

每个 NPC 维护**四本账**，严格分离：

| 账本 | 内容 | 来源 | 实现 |
|---|---|---|---|
| **亲历** (experience) | 亲眼看到/亲耳听到 | 直接观察 | `memory` + `observations` |
| **转述** (hearsay) | 别人告诉他的 | 对话 | `memory` with source |
| **推断** (inference) | 自己想的结论 | 推理 | `inferences` |
| **误解** (misconception) | 相信但错误的事 | 错误推断 | `beliefs` (可为假) |

**禁止**：所有 NPC 共享一个全局知识库。

## 二、Emily（玩家）

### 身份【电影事实】
- 前舞者，放弃过替补机会
- Kevin 的女友
- 对 Laurie 出现感到不安

### 心理状态【人物解读】
- 开场：不安、犹豫、被遗憾困扰
- **不是**一开始就有"替换计划"——这是逐步演变的结果
- 压力下：从被动观察者转为主动行动者

### 玩家认知 = Emily 认知
玩家看到的就是 Emily 看到的。不自动获得其他 NPC 的私人信息。

### 弧线【合理推断】
```
不安 → 困惑 → 恐惧 → 偏执 → 决断 → 行动
```

## 四、关系动态（可变数值）

| 关系 | 初始信任 | 可被事件改变 | 触发 |
|---|---|---|---|
| Em-Kevin | 中（有疑虑） | 是 | 对话选择、Laurie 事件 |
| Em-Laurie | 低 | 是 | 对话、Kevin 行为 |
| Mike-Lee | 高 | 是 | 秘密暴露 |
| Hugh-Beth | 高（表面） | 是 | 秘密暴露 |
| 全员-全员 | 高 → 崩溃 | 是 | 现实替换发现 |

**实现**：现有 `relationship` 系统（trust/familiarity）已支持，不需重写。

| 人物 | α 现实 | β 现实 | 差异类型 |
|---|---|---|---|
| Em | 遗憾+不安 | 关系和谐 | 【合理推断】 |
